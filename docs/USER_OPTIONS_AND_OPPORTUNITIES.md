## 1. One-line product story

**iBAS++** helps Bangladesh accounts / cadre officers and exam candidates in one place:

| Pillar | What users get today |
|--------|----------------------|
| **Pay & service** | 2026 salary fixation & arrears bills, pension / joining calculators, deductions reference |
| **Office work** | Circulars, policy, toolkit, schedule, contacts, guided workflows |
| **Learn & prepare** | Books, question bank, papers, QOTD, marathon, exam-week, progress |
| **Connect** | Community Q&A, blood bank |
| **Access** | Packages (exam-prep / basic / live), admin-managed grants |

## 2. Who you are presenting to

| Segment | Primary need | Best surface today |
|---------|--------------|-------------------|
| **Accounts / office staff** | Fast, correct salary TR / arrears; office tools | Web salary (often salary-focused) + mobile |
| **Exam candidates / learners** | Daily practice, papers, progress | Mobile (full) + web learning |
| **Office colleagues** | Find people, blood requests, ask community | Mobile + web community |
| **Admins / content owners** | Users, packages, books/QB, salary-access | Web admin |
| **Live-class attendees** | Join class when entitled | Web + mobile live |

When presenting, always name **which segment** each “more option” serves.

## 3. What users can already choose (current option menu)

Use this slide-style list in demos: “You can already…”

### 3.1 Pay & calculators
- Fix salary on NPS 2026 (phases).  
- Build arrears bills (months / bill duration).  
- Exceptional cases: increment exempt, promotion / higher scale (with / without NPS 2015 fixation).  
- Download TR Form 13 / 15.  
- Office staff bills; salary-access / bill limits.  
- Pension, joining-period, deductions lookup.

### 3.2 Learning
- Read books / regulations.  
- Practice questions; marathon filters.  
- Take papers (timed MCQ on **mobile**).  
- QOTD, exam-week, exam routine.  
- Track progress; exam-prep part switch.  
- Submit user-questions (where enabled).

### 3.3 Office & community
- Circulars / policy / toolkit / schedule.  
- Contacts & verify colleague.  
- Community threads.  
- Blood bank request / donor flows.  
- Guided workflow tasks (role-tagged).

### 3.4 Account
- Register / login (password).  
- Mobile: forgot / reset password.  
- Buy or view packages (pricing).  
- Device binding on mobile (one device).

## 4. Where you can offer **more** options (PM opportunity board)

Each row is something you can **present as a future choice** for users or for your roadmap pitch. Grouped by value, not by engineering wave.

### A. Trust & convenience (every user)

| Option to offer users | Why they care | Present as |
|----------------------|---------------|------------|
| **Forgot password on web** (same as mobile) | Don’t abandon web when password lost | “Reset from any device” |
| **SMS code after login** | Extra safety for salary / office data | “Login confirmation by SMS” |
| **SMS or email password recovery** | Works without email inbox | “Recover with your mobile number” |
| **Sign out all devices** | Phone lost / shared PC | “Secure my account” |
| **Clear “why is this locked?”** | Fewer support calls | “Upgrade / request access” button with reason |

### B. Salary & bills (office staff — high daily value)

| Option to offer users | Why they care | Present as |
|----------------------|---------------|------------|
| **In-app explainers** for promotion / bill duration / TR form | Less fear of wrong bill | “Guided salary help” |
| **Save / recall last bill inputs** | Repeat every month | “Continue last arrears” |
| **Office-wide download commitment** (already on register consent) | Social proof + product intent | Keep visible; optional reminder in salary hub |
| **Notify when bill quota low** | Avoid surprise block | “Bill balance alerts” |
| **Multi-staff batch print** improvements | Accounts clerks | “Office bill pack” |

### C. Learning — more paths without becoming a heavy LMS

| Option to offer users | Why they care | Present as |
|----------------------|---------------|------------|
| **“What should I do today?”** home | Reduces catalog hunting | Daily plan: QOTD + weak topic + one paper |
| **Timed exam on web** (parity with mobile) | Desktop practice | “Sit exam on computer” |
| **Synced bookmarks & history** | Change phones safely | “My saved questions everywhere” |
| **Streak / reminder** (push; later SMS) | Habit | “Don’t break your QOTD streak” |
| **Weak-topic coach** from progress data | Targeted practice | “Improve these 3 areas” |
| **Exam-week pack** as a clear product | Time-boxed value | “This week’s model tests” |
| **Learning path / syllabus unlock** (later) | Structured course feel | “Complete Part-1 path” |
| **Certificate of practice / path** (later) | Motivation / HR proof | “Download completion certificate” |
| **Candidate registration & results** (Module J, later) | Full exam journey | “Register → admit → result → appeal” |

### D. Office productivity

| Option to offer users | Why they care | Present as |
|----------------------|---------------|------------|
| **Personal + official schedule** with reminders | Miss fewer deadlines | “My office calendar” |
| **Toolkit checklists** as “start a task” | Actionable policy | “Run this checklist” |
| **Workflow inbox** simplified for SDO/DDO/AO | Approvals in one place | “My pending bills / tasks” |
| **Smart search** across circulars + books | Find rule fast | “Ask iBAS++” (search first; AI later) |

### E. Community & blood bank

| Option to offer users | Why they care | Present as |
|----------------------|---------------|------------|
| **Blood urgency + nearby** (if geo allows) | Faster donors | “Urgent request near you” |
| **Follow topics / experts** in community | Better answers | “Follow this subject” |
| **Verify colleague** as trust badge | Reduce fake profiles | Already partial — promote it |

### F. Packages & commercial options (presentable to buyers)

| Option | User sees | You can sell / grant |
|--------|-----------|----------------------|
| Free | QOTD, exam routine, (live stream module code) | Acquisition |
| **Exam-prep package** | Books, QB, exams, papers, exam-week, … | Core learning SKU |
| **Basic package** | Broader office / iBAS areas | Office SKU |
| **Live package** | Specific live classes | Event SKU |
| Admin **module grants** | Custom free/paid mix | Institutional deals |
| Salary **bill quotas** | Free calcs + approved bills | Office accounts product |

**Presentation tip:** Show one slide “Free vs Exam-prep vs Basic vs Live” with 3 bullets each — not a module-code dump.

### G. Admin / institutional options (present to office heads)

| Option | Value |
|--------|--------|
| Control who gets salary bills / free calcs | Cost control |
| Package + grant matrix per officer | Fair access |
| Content pipeline (books → questions → papers) | Exam-prep quality |
| Broadcast notifications | Campaigns / exam-week |
| Audit / overview metrics | Governance |

## 6. Priority for the project manager (decision matrix)

Score yourself when choosing what to offer next: **User value × Reach × Effort (inverse)**.

| Candidate offer | Reach | User value | Effort | PM lean |
|-----------------|-------|------------|--------|---------|
| Web forgot password | High | High | Low | **Do early when building** |
| Clear lock / unpaid CTA | High | Medium | Low | **Quick win** |
| Guided learning “today” | High learners | High | Medium | Strong |
| Web timed exam | Medium | High | Medium | Parity |
| SMS login confirm | High (sensitive apps) | High trust | Medium–High | After SMS provider |
| Salary bill alerts | Salary users | Medium | Low–Med | Strong for accounts |
| Sync bookmarks | Mobile heavy | Medium | Medium | Nice |
| Learning paths + certs | Institutions | High | High | Later |
| Module J candidate | Candidates | High | High | Later / funded |
| Full LMS (SCORM etc.) | Niche | Low for current users | Very high | Avoid unless required |

## 7. Packaging “options” as user journeys (demo scripts)

### Journey 1 — Accounts officer (15 min)
Register → salary consent → fix pay → arrears → TR download → (optional) staff bill.

**More options to mention:** reset on web, SMS login, bill alerts, office pack.

### Journey 2 — Exam candidate (15 min)
Home → QOTD → exam-prep part → paper (mobile timed) → progress.

**More options to mention:** daily plan, web exam, streak reminder, certificate later.

### Journey 3 — Office head / admin (15 min)
Users → grants / packages → salary-access → content publish → notify.

**More options to mention:** institutional packages, audit overview, candidate portal later.

## 8. Messaging do’s and don’ts

| Do | Don’t |
|----|--------|
| Speak in user jobs (“download my bill”, “practice today’s questions”) | Lead with module codes (`PAPER`, `QOTD`) |
| Separate **today** vs **coming later** | Promise SMS/LMS as if already live |
| Offer **choices** (free / paid / admin grant) | One giant feature list |
| Tie options to segments | Same pitch for salary clerk and candidate |
